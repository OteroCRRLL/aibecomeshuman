# prompts/

Every text the model receives lives here, separate from the code. Each run stores the
hash of every file in its manifest, so you always know which prompts a run used.

Layer stack (from most fixed to most variable), as it will be assembled in phase 1:

1. `constitution/`: fixed rules (in-world, evidence only, output format).
2. `roles/`: instructions per technical role (observer, decider, reflector, judge). *Phase 1.*
3. `characters/`: the character's base sheet (written by us, never game text).
4. *Current personality*: generated by memory. *Phase 2.*
5. `directives/`: the run directive (`default.md` or any override).
6. *Composed context and task*: assembled by the context composer.

To change a run's directive, create `directives/<name>.md` and set
`directive = "<name>"` in `config/runs/<run>.toml`. No code changes needed.
