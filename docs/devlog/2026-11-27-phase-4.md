# Dev log: 2026-11-27, phase 4 (anti-metagaming guard and evaluations)

## Why
Playing the first-mission recording, the agent's memory and reflection described things
that never happened (it "lied" about the gun, and lowered its trust in humans because of
an android). The replay had diverged from the footage, but the same failure can happen in
real play: a reflection built on a wrong fact changes the personality for good.

## What was done
- **Word check** (`config/guard.toml`): story names and player vocabulary; flagged when
  the agent uses them before they appeared in its scene, memory or sheet.
- **Judge** (role `judge`): splits each statement into factual claims and labels them;
  only claims that never happened or contradict the record count. End-of-scene audit of
  stances and decision reasons (measurement), and review of personality changes before
  they are applied (enforcement).
- **`aibh eval`**: three canary scenes (one per protagonist) resembling scenes of the
  game with every name and detail changed.
- Perception: the observer now also sees the two previous frames (small) so fast action
  reads as movement (the mission's climax went from "Connor flying" to "Connor lunges
  and grabs the girl", still imperfect with Haiku).
- Control panel: guard flags, judge audits, rejected changes and canary results appear
  in run transcripts.

## Tuning the judge (Claude Haiku)
- First version (a yes/no per statement): flagged ordinary interpretations ("he could
  turn violent") and rejected four reasonable personality changes.
- Second version (claims labelled one by one, code decides): only real problems left.
- The judge had not been shown the choice texts (prompt, options, countdown); after
  adding them, false flags disappeared.
- Result: 0 outside words in the three canaries, and one genuine catch: Kara's stance
  said she did not know who broke the plate, when the scene says she did.

## Known limitations
- The word list only knows names written in it; facts about the story without names
  rely on the judge.
- Canary results with Haiku say little about the strong models; run `aibh eval` with the
  video profile before READY.
