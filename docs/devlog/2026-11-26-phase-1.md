# Dev log: 2026-11-26, phase 1 (decisions without the game)

## What was done
- **Budget**: prices per model, cost per call and per run, a project-wide cap ($10 during
  development) and a per-run cap ($0.50). Expensive models are locked behind `--unlock-premium`.
- **Layered prompts**: constitution → role → character → directive → output language.
- **Decider**:
  - keeps a *stance* for the scene (strong model, off the clock);
  - critical untimed choices go to the strong model with the full scene and must cite evidence;
  - timed choices go to the fast model with the stance;
  - if the model is too slow or fails, a local rule picks the option closest to the stance.
- **Scenario simulator**: three invented scenes (Markus, Connor, Kara) with timed and
  untimed choices, in the real game's language mix (English observations, Spanish text).
- **Directives**: the run's directive can be overridden from the command line or swapped
  mid-scene; `bad_ideas` is the first example of an override.
- `aibh play` and `aibh budget` commands.

## Decisions made
- Development with a single AI (Claude Haiku in every role) until everything works.
- The agent writes its reasoning in Spanish, for the audience.

## Control panel (added at the end of phase 1)
- `aibh ui`: local web page to play scenarios and watch decisions live, browse runs,
  check spend, edit budget caps and the model per role, and read the prompts.
- Config edits keep the files' comments and are rolled back if they break validation.

## First real runs with Claude Haiku
- All three scenes plus `bad_ideas`: about **$0.002 per scene**, timed choices answered in
  1.7–2.5 s, no fallbacks, evidence valid in every critical decision.
- Decisions matched each character sheet, and `bad_ideas` changed the choices.
- Tuning after the first runs:
  - stances were long and repetitive → now at most ~40 words, and the model can answer
    "unchanged" (`stance.kept`);
  - under an overriding directive the stance either restated the rule or ignored it →
    it now states what the character will actually do under the directive, which keeps
    the timeout fallback consistent with the directive;
  - reasoning mentioned internal words ("stance", "directive") → forbidden in the role prompts.
- Known minor issue: small invented details (e.g. a room that is not in the scene).
  To be handled by the anti-metagaming guard (phase 4).

## Control panel follow-ups
- The panel re-reads `.env` on every request (a key added after startup now works).
- Settings tab: save/replace the API key (write-only) and a "Test connection" button.
- Local-only protection: requests must target 127.0.0.1/localhost, writes must be JSON
  and come from the panel itself.
